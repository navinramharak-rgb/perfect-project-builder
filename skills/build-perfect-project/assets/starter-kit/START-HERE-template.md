## Two things everybody gets wrong

1. **The Instructions get pasted, not uploaded.** `1-PASTE-THIS/project-instructions.md` goes into the Instructions box inside the project. If you upload it as a knowledge file instead, the project will look like it is ignoring its own rules.
2. **Claude cannot see the project name or description.** Those fields are for you. Anything Claude needs to know lives in the Instructions or in the uploaded files.

## Build it

1. Go to claude.ai, click **Projects**, click **Create project**.
2. Name it `[Project Name]`.
3. Open the **Instructions** area. Copy all of `1-PASTE-THIS/project-instructions.md` and paste it in. Do not edit it.
4. Open **project knowledge**. Upload every file from `2-UPLOAD-THESE/`.

2. When you correct the same thing twice, make it a rule in `01_Voice_and_Non_Negotiables.md`.
3. When a price, link, or date changes, change it in `03_Source_of_Truth.md` and nowhere else.
