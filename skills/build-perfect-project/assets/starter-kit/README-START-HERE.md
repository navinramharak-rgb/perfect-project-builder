# Starter Kit

These five files are the core knowledge base for a focused Claude Project. Fill them in (or have your assistant fill them in with you), then upload them to your project's knowledge.

Rules that make this work:

1. **One topic per file.** Retrieval finds focused documents; it misses facts buried in mega-documents.
2. **Real material only.** Paste actual past work, actual sent emails, actual approved claims. "Be conversational" teaches nothing; five real captions teach everything.
3. **Keep `03_Source_of_Truth.md` current.** When a fact changes, change it there — never leave two versions alive.
4. **Feed the loop.** When an output performs, add it to `02_Gold_Standard_Examples.md` with a note on why it worked.
5. **Upload text, not scans.** Project files cap at 30MB each and Claude extracts text only, except for PDFs. If your source is a scan, a screenshot, or an image-heavy PDF, copy what matters into one of these markdown files instead of uploading the original.
6. **Claude never sees your project name or description.** Those fields are for you. Anything Claude needs to know goes in the Instructions field or in these documents.

Fill-in order: 00 → 02 → 01 → 03 → 04. Examples before voice — the voice file is easier once real examples are in front of you.
