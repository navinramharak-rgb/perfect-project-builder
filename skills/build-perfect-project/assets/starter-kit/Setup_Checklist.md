# Setup Checklist

Tick these off in order. Stop at any step that does not work and say what you see.

## Build the project

- [ ] Opened claude.ai and found **Projects** in the left sidebar
- [ ] Clicked **Create project** and named it
- [ ] Found the **Instructions** area inside the project
- [ ] Opened `1-PASTE-THIS/project-instructions.md`, selected all, copied
- [ ] Pasted it into the Instructions box and saved, without editing it
- [ ] Found the **project knowledge** area
- [ ] Uploaded every file from `2-UPLOAD-THESE/`
- [ ] Confirmed the knowledge list shows the same number of files that folder contains: ______

## Prove it works

- [ ] Started a new chat inside the project
- [ ] Ran the first prompt from `3-TRY-THESE/starter-prompts.md`
- [ ] Read the output against the success criteria
- [ ] Pasted the output back to Claude for a diagnosis

## If the output was not right

- [ ] Generic and could be anyone → added three real examples to `02_Gold_Standard_Examples.md`
- [ ] Made up a fact, price, or link → added that fact to `03_Source_of_Truth.md`
- [ ] Wrong shape or missing a section → tightened the **Output format** section of the Instructions
- [ ] Right content, wrong tone → added two real lines you would say and two you never would to `01_Voice_and_Non_Negotiables.md`
- [ ] Ignored the rules entirely → check the Instructions went in the **Instructions box**, not uploaded as a file

## Keep it alive

- [ ] Know where to paste a great output so the project learns from it
- [ ] Know where to change a price or a link when it changes
- [ ] Have a date to come back and fill anything marked empty: ______________
